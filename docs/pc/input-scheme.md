# 输入方案（桌面版）

> 平台：桌面版（曦码·曜）。当前内容以 Windows 预览版为准，Linux / macOS 即将支持。

在「设置 → 输入方案」中管理方案。页面右上角有三个按钮：**部署方案**、**打开数据目录**、**导入方案**；下方是三个标签页：**已安装**、**已下载**、**方案词表**。

## 内置方案（安装包 seed）

安装包自带 9 个方案，首次启动时部署到 `%APPDATA%\xime\rime`，无需下载：

| 方案 | schema_id | 默认启用 | 说明 |
|------|-----------|:--------:|------|
| 五笔86 | `wubi86` | ✅ | 纯五笔输入 |
| 五笔98 | `wubi98` | — | 五笔98 输入 |
| 五笔拼音 | `wubi86_pinyin` | ✅ | 五笔+拼音混合输入 |
| 简入繁出 | `wubi86_trad` | ✅ | 五笔输入、繁体输出 |
| 拼音混输繁体 | `wubi86_trad_pinyin` | ✅ | 五笔+拼音混输、繁体输出 |
| 简体拼音 | `pinyin_simp` | ✅ | 简体拼音输入 |
| 拼音九键 | `t9_pinyin` | — | 九宫格拼音（Windows 端无对应触屏界面） |
| 手写输入 | `handwriting` | — | 手写识别（Windows 端无对应界面） |
| 大写数字 | `numbers` | — | 数字输入 |

- 上表标 ✅ 的 5 个方案默认启用；未默认启用的方案同样在「已安装」列表中，点击选中并完成部署后即可使用。
- 内置方案随安装包提供；安装目录不再附带额外的 Rime 示例数据目录，方案所需配置由内置方案自带。
- 升级时只覆盖内容有变化的文件，且不会覆盖 `*.custom.yaml`（用户定制）与未启用的内置方案文件。

## 方案来源与归属

「已安装」列表按**方案包**分组，组名即来源：

| 分组 | 徽标 | 含义 |
|------|------|------|
| 内置方案包 | 内置 | 安装包自带的方案 |
| 本地方案 | 本地 | 用户手动放入 `rime` 目录、或旧版本遗留下来的方案文件；程序**不会删除**这些文件 |
| 第三方包 | 第三方 | 从扩展商店或导入安装的方案包，组名就是包 id（如 `rime-ice`） |

每个方案行会显示 **当前**（正在使用）与 **未启用**（还没有部署产物，点击后会先部署再切换）。

## 导入方案

点击右上角「导入方案」打开弹窗，支持四种来源：

1. **拖入**：把 `.zip` / `.tar.gz` 方案包拖进窗口；
2. **本地文件**：填写路径或点「浏览」选择；
3. **远程 URL**：填写方案包的下载地址；
4. **从剪贴板读取文件 / URL**：复制了文件路径或下载链接后一键填入。

其他行为：

- 一次只能用一种来源；方案名称可以修改，默认由文件名生成（如 `rime-ice.zip` → `Rime Ice`）。
- 支持压缩包内嵌套目录：会自动下钻单层或多层同名目录，直到找到顶层 `.schema.yaml`。
- **安装前预检**：先校验压缩包结构与顶层方案文件，坏包直接报错，不会先卸载已有方案。
- 名称已存在时会提示改名，或先卸载/删除同名包。
- 下载有进度显示；完成后包会落到 `market/<名称>/`，并接着走正常的安装与冲突确认流程。
- 导入完成后需要在「已安装」中选中方案并部署才会生效。

## 管理已下载的方案包

「已下载」标签页列出 `market/` 中已下载的方案包，每张卡片有：

- **安装**：解压并部署到 `rime` 目录（若本机已有其他方案包，会先弹「文件冲突」确认）；
- **卸载**：移除已安装的方案包；
- **删除**：删除已下载的包文件；方案已安装时按钮置灰为「先卸载」。

## 内置方案的清理与恢复

「已安装」页底部有内置方案包的卡片：

- **清理内置方案**：需要至少保留一个非内置方案可用。清理时会先把当前方案切换到剩余方案并完成部署，再删除内置方案文件，并写入「已清理」标记——之后重启也不会再自动注入内置方案。被其他方案包声明共享的词典会保留。
- **恢复默认方案**：内置方案被卸载或不完整时，卡片会提示「内置方案已卸载或不完整」，点击「恢复默认方案」可从 `market/builtin/` 备份还原；若本机有第三方方案包，会先提示卸载。还原完成后自动部署。

清理不会删除备份，随时可以恢复。

## 方案隔离与冲突

为避免多个来源的方案文件混装在同一目录，**同一时刻只保留一个方案来源**。安装新方案包时，如果本机已有其他方案包，会弹出「文件冲突」确认：

- 卸载旧包会删除：该方案包的文件、它生成的 `<方案>.custom.yaml`、短语表与部署缓存；
- 会保留：输入记录（`*.userdb`）、已下载的安装包、`market/builtin/` 中的内置方案备份。

## 切换与部署

- 在「已安装」列表中点击方案即可切换；方案若还没有部署产物，会先提示「正在部署，请等待」，部署完成后自动切换，不需要手动再点一次。
- 手动部署入口：「输入方案」页右上「部署方案」，或「快捷键」页的「重新部署」。
- 部署期间输入可能短暂不可用；启用的方案与词典越多，部署越久。

## 兼容性说明

方案包沿用 Rime 的通用规范，Windows 版可直接使用：

- 格式：`.zip` 或 `.tar.gz`，包内需包含 `.schema.yaml` 与对应的 `.dict.yaml`；
- 嵌套目录：压缩包外层带一层或多层同名目录时会自动下钻，找到顶层 `.schema.yaml` 为止；
- 子目录：雾凇拼音（rime-ice）等方案的 `cn_dicts/`、`en_dicts/`、`opencc/` 会被正确解压到 `rime/` 下；
- 直接打包的方案文件，或从 GitHub 下载的带外层目录（如 `rime-ice-main/`）的压缩包，都可以直接导入。

导入前会做一次预检：包内没有顶层 `.schema.yaml` 或格式损坏时直接报错，不会先卸载已有方案。
