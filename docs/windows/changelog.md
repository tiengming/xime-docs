# 更新记录（Windows 版）

> 平台：Windows（曦码·曜 0.3.1 预览）。

## 2026-10-27

### 新增

- **方案来源管理**：内置方案明确为安装包自带的 seed；用户手动放入或旧版本遗留的方案文件归入「本地方案」，程序不会删除
- **内置方案清理与恢复**：可清理内置方案（写入「已清理」标记，重启不再注入），也可从备份一键恢复默认方案
- **导入方案**：输入方案页新增「导入方案」，支持拖入、本地路径、远程 URL、剪贴板四种来源；支持 `.zip` / `.tar.gz`、嵌套目录自动识别，安装前预检坏包
- **删除已下载的方案包**：已安装时需先卸载

### 优化

- 安装/卸载/还原方案后，列表在后台重新扫描，设置程序不再卡顿
- 切换到尚未部署的方案时，先提示「正在部署，请等待」，部署完成后自动切换，不再直接报失败
- 方案名称支持中文与空格，重名时提示改名而不是覆盖

### 修复

- 修复部署后方案全部显示「未启用」的问题

## 2026-10-26

### 新增

- **内置计算器**：中文输入状态按 `=` 进入，候选栏实时显示结果，空格 / 回车 / `=` 上屏；支持鼠标点选与方向键切换结果/原式
- 候选词支持鼠标点击上屏与悬停高亮

### 优化

- 数字自动识别默认开启：直接输入数字会先进入计算缓冲，按运算符、空格、字母或失焦时提交；可在 `rime/xime.custom.yaml` 中关闭

### 修复

- 退出计算器或按方向键后，光标处残留的旧组词内容会立即收起

## 2026-10-23

### 修复

- 修复 MSI / MSIX 安装包缺少语音运行库导致语音功能不可用
- 安装包不再附带 Rime 示例数据目录，避免示例方案混入用户的 `rime` 目录
- 安装包内的方案改为随包提供，首次启动部署到用户数据目录
